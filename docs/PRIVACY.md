# Data flow and privacy

For the Ollama engine, text and selected images go to an installed model through http://127.0.0.1:11434. The app rejects cloud model names and remote-model metadata, ignores configured proxies for inference, and has no hosted inference fallback. This is a local client boundary, not a network sandbox for Ollama. Ollama can independently check updates, download models, or use its configured cloud features. Review its settings if you need an offline environment.

Dictation requests Apple on-device speech recognition only after checking platform support. Unsupported languages/recognizers report an error instead of using network speech recognition. Microphone and Speech Recognition access are requested only when the user starts recording. Closing the panel stops capture. No audio recordings are saved by this app.

Prompts, responses, and selected image bytes are held in process memory; setup-completion state is saved in UserDefaults. The app does not save conversation history. Copy explicitly writes to the system clipboard; Paste explicitly reads clipboard text; Share hands the selected response to the user's chosen sharing service; Save writes a selected file. Browser search sends the prompt to the chosen browser's search URL only when clicked. Sharing, browser use, macOS services, clipboard history tools, and Ollama logs have their own policies. No app analytics SDK is included. The app uses OS logging for shortcut registration and dispatch without prompt text.

AI output can be wrong. The app does not browse pages, verify sources, generate/edit images, or execute model tools. It does not promise factual correctness or automatic citations.

The Apple engine uses `SystemLanguageModel.default` through Apple’s Foundation Models framework and an independent `LanguageModelSession` per request. It does not instantiate a Private Cloud Compute model. App Store configuration exposes this engine only and has no network-client entitlement. Availability depends on the OS, hardware, enabled Apple Intelligence, and system model readiness. Prompts are not written to app-owned history. The app includes a privacy manifest declaring UserDefaults access for its own setup/window preferences (CA92.1), no tracking, and no developer-collected data. App Store privacy answers still require maintainer review before submission.
