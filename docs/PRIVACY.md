# Data flow and privacy

For the Ollama engine, text and selected images go to an installed model through http://127.0.0.1:11434. The app rejects cloud model names and remote-model metadata, ignores configured proxies for inference, and has no hosted inference fallback. This is a local client boundary, not a network sandbox for Ollama. Ollama can independently check updates, download models, or use its configured cloud features. Review its settings if you need an offline environment.

Dictation requests Apple on-device speech recognition only after checking platform support. Unsupported languages/recognizers report an error instead of using network speech recognition. Microphone and Speech Recognition access are requested only when the user starts recording. Closing the panel stops capture. No audio recordings are saved by this app.

Prompts, responses, and selected image bytes are held in process memory; setup-completion state is saved in UserDefaults. The app does not persist conversation history to disk. Text chat holds at most eight turns in process memory and supplies the most recent four to the selected engine, truncated to 1,200 user and 1,800 assistant characters per turn. Rewrite and image requests exclude that context. Clear removes the current conversation, attachment, and run receipt. Copy explicitly writes to the system clipboard; Paste explicitly reads clipboard text; Share hands the selected response to the user's chosen sharing service; Save writes a selected file. The Actions workspace requires a review and approval of the exact query, HTTPS destination, or basic Mac-summary scope. Approved search opens DuckDuckGo in Safari; the provider receives the query. Approved HTTPS navigation sends the destination to Safari. Approvals expire after five minutes and are not reusable permissions for arbitrary actions. Sharing, browser use, macOS services, clipboard history tools, and Ollama logs have their own policies. No app analytics SDK is included. The app uses OS logging for shortcut registration and dispatch without prompt text.

Recognized clock/date requests read the Mac system clock and time-zone database directly. An approved basic Mac summary reads macOS version, logical processor count, physical RAM capacity, free space on the home volume, current time, and time zone. It does not read personal files, screen or app contents, passwords, browsing history, or process lists. The summary and run receipt stay in process memory unless explicitly copied, shared, or saved.

AI output can be wrong. The app does not browse pages, verify sources, generate/edit images, or run arbitrary model-selected tools. Its typed action executor is limited to the approved Safari navigation and basic Mac-summary operations described here. It does not promise factual correctness or automatic citations.

The Apple engine uses `SystemLanguageModel.default` through Apple’s Foundation Models framework and a new `LanguageModelSession` per request, with the bounded recent text context explicitly included. It does not instantiate a Private Cloud Compute model. App Store configuration exposes this engine only and has no network-client entitlement. Availability depends on the OS, hardware, enabled Apple Intelligence, and system model readiness. Prompts are not written to app-owned history. The app includes a privacy manifest declaring UserDefaults access for its own setup/window preferences (CA92.1), no tracking, and no developer-collected data. App Store privacy answers still require maintainer review before submission.
