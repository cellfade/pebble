# Data flow and privacy

For the Ollama engine, text and selected images go to an installed model through http://127.0.0.1:11434. The app rejects cloud model names and remote-model metadata, ignores configured proxies for inference, refuses HTTP redirects before forwarding payloads, and has no hosted inference fallback. This is a local client boundary, not a network sandbox for Ollama. Ollama can independently check updates, download models, or use its configured cloud features. Review its settings if you need an offline environment.

Dictation requests Apple on-device speech recognition only after checking platform support. Unsupported languages/recognizers report an error instead of using network speech recognition. Microphone and Speech Recognition access are requested only when the user starts recording. Closing the panel stops capture. No audio recordings are saved by this app.

Prompts, responses, and selected image bytes are held in process memory; setup-completion, appearance and window preferences are saved in UserDefaults. The app does not persist conversation history to disk. Text chat holds at most eight turns in process memory and supplies up to four recent turns to the selected engine. Each included user message is shortened to 192 UTF-8 bytes and each answer to 320 bytes. The current request and included history share a 2,304-byte budget; older turns are omitted to fit. Requests over 2,048 UTF-8 bytes are refused without truncating the draft. These conservative bounds are not exact token counts. Rewrite and image requests exclude that context. Clear removes the current conversation, attachment, and run receipt. Copy explicitly writes to the system clipboard; Paste explicitly reads clipboard text; Share hands the selected response to the user's chosen sharing service; Save writes a selected file. The Actions workspace requires a review and approval of the exact query, HTTPS destination, or basic Mac-summary scope. Approved search opens DuckDuckGo in Safari; the provider receives the query. Approved HTTPS navigation sends the destination to Safari. Approvals expire after five minutes and are not reusable permissions for arbitrary actions. Sharing, browser use, macOS services, clipboard history tools, and Ollama logs have their own policies. No app analytics SDK is included. The app uses OS logging for shortcut registration and dispatch without prompt text.

Recognized clock/date requests read the Mac system clock and time-zone database directly. An approved basic Mac summary reads macOS version, logical processor count, physical RAM capacity, free space on the home volume, current time, and time zone. It does not read personal files, screen or app contents, passwords, browsing history, or process lists. The Mac summary stays in the Actions view and process memory; Pebble does not attach it to model requests or expose it through chat copy/share/save controls. Run receipts also stay in memory until Clear or Quit.

AI output can be wrong. The app does not browse pages, verify sources, generate/edit images, or run arbitrary model-selected tools. Its typed action executor is limited to the approved Safari navigation and basic Mac-summary operations described here. It does not promise factual correctness or automatic citations.

The Apple engine uses `SystemLanguageModel.default` through Apple’s Foundation Models framework and a new `LanguageModelSession` per request, with the bounded recent text context explicitly included. It does not instantiate a Private Cloud Compute model. App Store configuration exposes this engine only and has no network-client entitlement. Availability depends on the OS, hardware, enabled Apple Intelligence, and system model readiness. Prompts are not written to app-owned history. The app includes a privacy manifest declaring UserDefaults access for its own preferences (CA92.1) and disk-space access to display a local capacity summary (85F4.1), no tracking, and no developer-collected data. App Store privacy answers still require maintainer review before submission.
