PRODUCT / AGENT CONTRACT

A little light, close at hand.

Native, readable, explicit

SwiftUI semantic colors, an opaque system window background for reliable contrast, native controls, visible labels, and selectable response text. Keep the primary prompt and send action dominant. Secondary tools belong in More.

Input and feedback

Enter sends, Shift-Enter inserts a newline, marked-text composition takes precedence. Dictation edits the prompt and never auto-sends. A system progress indicator and elapsed time explain waiting; cancellation remains visible.

Brand gate

The final brand direction requires owner selection from the concept board. Generate a true SVG mark after selection, then make dark/light and monochrome variants. App icon can be dimensional; menu bar mark must be a simple template silhouette.

Acceptance

Inspect real rendered light/dark, waiting, setup, error, and image-attachment states. Check short displays and keyboard navigation. Never use generated mockups as product screenshots or claim a working flow from source review alone.
