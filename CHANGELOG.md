## 0.3.0-beta.1 — Developer preview

- Approved Pebble stone identity with floating ink eyes and a smiling line; cobalt remains the interface accent.
- Interaction/layout and transactional composer fixes, with accepted real beta captures.
- Bounded recent text context and inspectable engine/model/input/context/timing run details; no persistent chat storage.
- Recognized clock/date requests use the Mac system clock and supported time zones directly.
- Explicit approval for an exact Safari search, credential-free HTTPS link, or basic read-only Mac capacity summary. Five-minute proposal expiry; unsupported actions remain unavailable.
- Updated brand/marketing Figma board using an accepted real app capture.

This is a developer preview, not notarized or App Store approved. Release publication follows final CI and package verification. Safari navigation does not fetch or cite web pages. Image generation/editing, durable memory, arbitrary Mac control, and token streaming remain unavailable.

## 0.2.0 — Developer preview

- Native menu bar chat and rewriting through local Ollama.
- On-device dictation, Control-Space registration, Enter/Shift-Enter composition handling.
- Image attachments with vision-model validation.
- Explicit paste, copy, share, save, browser search, and clear controls.
- Waiting indicator, elapsed time, cancellation, and accessibility labels/announcements.

Image generation, verified web citations, persistent conversation history, token streaming, signed/notarized public distribution, and automatic updates are not included.
